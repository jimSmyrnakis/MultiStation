\doxysubsection{Detailed Description}
\doxylink{struct_multi_station_1_1_job}{Job} System with fifo schedule algorithm . Supports local/affinity queues and global for scheduling the jobs base on some specific worker or global -\/\texorpdfstring{$>$}{>} any worker available . The parent Thread is part of the schedule algorithm , usefull method is the wait\+For\+All that makes him enable for schedulling with the rest workers .
