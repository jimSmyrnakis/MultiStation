\doxysubsection{Detailed Description}
Maintains an acyclic parent-\/child hierarchy of entity IDs. This class manages hierarchy only; it does not create or destroy registry entities, manage components, or verify that IDs exist in an \doxylink{class_multi_station_1_1_e_c_s_registry}{ECSRegistry}. 

\begin{DoxyWarning}{Warning}
Not thread-\/safe. 
\end{DoxyWarning}
\begin{DoxyNote}{Note}
Copying and moving are disabled . 
\end{DoxyNote}
