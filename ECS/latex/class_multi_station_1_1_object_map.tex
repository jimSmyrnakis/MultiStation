\doxysubsection{Detailed Description}
Catalog of known component and module types for runtime lookup. 

Stores Comp\+ID-\/to-\/\+Obj\+ID and Module\+ID-\/to-\/\+Obj\+ID associations. Each association describes a C++ type, not an object instance. Repeated addition of the same type preserves the same association.

Entries remain until this map is destroyed; removing a module or unregistering a component elsewhere does not remove its type association. A successful lookup therefore does not imply that an instance exists or that the component/module is currently registered with its manager.

\begin{DoxyNote}{Note}
IDs are runtime-\/only and must not be used as persistent identifiers in saved data. Persistent identity is handled separately, using UUIDs. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Not thread-\/safe. Serialize additions and lookups when modifying the map; it does not provide synchronization. 
\end{DoxyWarning}
