\doxysubsection{Detailed Description}
An interface for components, providing a common base for different component types. 

\begin{DoxyAuthor}{Author}
Dimitris Smyrnakis
\end{DoxyAuthor}
This way we ensure that all components can be treated polymorphically , as well for each different component type we can get a unique type ID and version control for each component instance to know when it is modified. Fethermore , this interface will provided anybody that creates a new component with all the desire metadata to use .
