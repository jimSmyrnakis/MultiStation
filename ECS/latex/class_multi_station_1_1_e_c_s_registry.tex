\doxysubsection{Detailed Description}
The \doxylink{class_multi_station_1_1_e_c_s_registry}{ECSRegistry} class manages the registration and retrieval of component with different types , also entity creation / remove and components types to entities signatures . 

\begin{DoxyWarning}{Warning}
Not thread-\/safe. 
\end{DoxyWarning}
\begin{DoxyNote}{Note}
Unexpected exceptions terminate the application. 

Components (template type T) should support assigments and default contructor . 
\end{DoxyNote}
