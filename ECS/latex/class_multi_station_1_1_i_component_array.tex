\doxysubsection{Detailed Description}
An interface for \doxylink{class_multi_station_1_1_component_array}{Component\+Array} classes, providing a common base for different component types. 

This way we ensure that all component arrays can be accessed polymorphically , as well for each different component type (templates) .
