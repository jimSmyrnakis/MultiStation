\doxysubsection{Detailed Description}
Base interface for a module\textquotesingle{}s system, driven by \doxylink{class_multi_station_1_1_system_manager}{System\+Manager}. 

After module Init(), the manager calls \doxylink{class_multi_station_1_1_i_system_a3d01487555ed588dff7a18d0230a7831}{On\+Attach()}, then \doxylink{class_multi_station_1_1_i_system_af85a7080085389cad6ba8a7453f584eb}{On\+Enable()}. Each frame it processes enable/disable changes before calling \doxylink{class_multi_station_1_1_i_system_ae33de4bfba0297647ded209f4bebdca5}{On\+Update()} on enabled systems, in module registration order. \doxylink{class_multi_station_1_1_i_system_af85a7080085389cad6ba8a7453f584eb}{On\+Enable()} and \doxylink{class_multi_station_1_1_i_system_a734f6915740708e24a68bd46abb08ac3}{On\+Disable()} may repeat as the requested enabled state changes.

When the module is removed or the manager shuts down, \doxylink{class_multi_station_1_1_i_system_a734f6915740708e24a68bd46abb08ac3}{On\+Disable()} is called if the system was last processed as enabled, then \doxylink{class_multi_station_1_1_i_system_a590d9fa521e0d7206af511769e799597}{On\+Dettach()}, followed by module Fini(). Destruction alone does not invoke these callbacks.

\begin{DoxyNote}{Note}
All lifecycle callbacks have empty default implementations. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
Callbacks must not let exceptions escape, add or remove modules, or recursively update the manager. 
\end{DoxyWarning}
