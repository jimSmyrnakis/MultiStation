Detailed Description

Responsible for creating , destroying , getting and registration's of components for all the ecs registrie's of the application (A common ground) . Provides already existing storage's and manages the registration's and lifetimes of each .

Clears components and releases the slot for another scene/registry.

Parameters

Retains registered arrays and their capacity for reuse, destroys component instances, and removes the callback. Invalid or already released IDs have no effect. Component pointers and views must no longer be used.

template<typename T>
void MultiStation::CentralStorageManager::Register ( void )
staticnoexcept

Registers T across all slots, including slots for future scenes.

Template Parameters
TComponent type supported by ComponentArray.

Allocates an independent empty array per slot, so scenes do not need to register the type individually. Initializes the pool if needed.

Precondition
T is not already registered; duplicate calls replace existing arrays.
Note
Not thread-safe; serialize registration with other ECS operations.

◆ Unregister()

template<typename T>
void MultiStation::CentralStorageManager::Unregister ( void )
staticnoexcept

Unregisters T globally, deleting its arrays and component instances.

Template Parameters
TComponent type to unregister.

Calls each slot's callback before deleting its array and erasing the entry. Does nothing if T is not registered.

Precondition
Callbacks update registry bookkeeping without modifying storage maps or reentering registration operations. ECS operations are serialized.
Warning
Invalidates pointers, references, and spans to T in every scene.
