typedef void(* MultiStation::JobFunction) (struct Job job)

A JobFunction is a function pointer that defines the signature of the function that can be executed as a job.

Parameters
[in]dataA pointer to the data that will be passed to the job function when it is executed.
[in]workerIDThe ID of the worker thread that is executing the job.
[in]idThe ID of the job.
[in]blockIDThe ID unique to the parallel for block that this job belongs to.
[in]sizeThe total number of jobs in the parallel for block that this job belongs to.
