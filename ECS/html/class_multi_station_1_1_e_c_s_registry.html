Detailed Description

The ECSRegistry class manages the registration and retrieval of component with different types , also entity creation / remove and components types to entities signatures .

Warning
Not thread-safe.
Note
Unexpected exceptions terminate the application.
Components (template type T) should support assigments and default contructor .

Returns the stored name of a component type using its runtime ID.

Parameters
componentThe component type ID whose name is requested.
Returns
A const reference to the registered type's name, or the shared fallback string "none" if the ID is not registered.
Note
Registered names come from typeid(T).name() and are implementation-defined.
Warning
A reference to a registered name becomes invalid when that type is unregistered or this registry is destroyed. Copy the string if it must outlive that storage. The fallback string has static storage duration and is independent of the registry.

◆ UnregisterComponent()

template<typename T>
CompID MultiStation::ECSRegistry::UnregisterComponent ( void )
noexcept

Unregisters component type T and destroys all its stored components.

Template Parameters
TThe component type to unregister.

Removes T from every entity's signature without removing the entities. If T is not registered, the registry is left unchanged.

Returns
The unregistered component type ID, or MultiStation::BAD_ID if T was not registered.
Note
Retained for API symmetry with RegisterComponent(); normal registry use does not require explicit unregistration. Registry destruction releases all storage.
Warning
Invalidates all pointers, references, and spans to components of type T. Views of affected entity signatures may also be invalidated or have changed contents.
