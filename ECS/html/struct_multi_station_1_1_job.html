Detailed Description

A JobFunction is a function pointer that defines the signature of the function that can be executed as a job.

Parameters
[in]JobA copy of the job so user can retreive more information

typedef void (*JobFunction)(struct Job job);

A job is a unit of work that can be executed by a worker thread. The Job struct defines the function to execute and the attributes of the job .
