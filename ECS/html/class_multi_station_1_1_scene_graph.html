Detailed Description

Maintains an acyclic parent-child hierarchy of entity IDs. This class manages hierarchy only; it does not create or destroy registry entities, manage components, or verify that IDs exist in an ECSRegistry.

Warning
Not thread-safe.
Note
Copying and moving are disabled .

Parameters

Returns
Child IDs in stored order, or an empty span if there are no children, the entity is absent, or entity equals nullEntity.
Warning
The span borrows graph storage. Reacquire it after hierarchy changes; it must not be used after the graph is destroyed.
