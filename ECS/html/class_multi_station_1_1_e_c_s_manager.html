Detailed Description

The ECSManager class is responsible for managing entities and component's . Components / Entities that Created/Removed/Replaced are not happen directly but they requested to be happen in some other safe moment from the System Manager Side , this is done to ensure that all operations are not going to create data races with the systems that are executed in the same phase .
