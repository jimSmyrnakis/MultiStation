Detailed Description

Contains the interface of system module for developers to implement.

Warning
Exceptions terminate the engine , prefer catch them inside the methods and handle them there .

◆ OnSceneActivate()

virtual void MultiStation::ISystemModule::OnSceneActivate ( Scene & scene)
virtualnoexcept

Applies module state for a scene entering active use.

Parameters
[in,out]sceneLive scene selected as active by the caller.

Use this to bind scene resources or apply its settings. A loaded scene can be activated repeatedly, with deactivation between activations. The default implementation does nothing.

Precondition
Scene creation/loading is complete. The safe-stage and callback restrictions documented on OnSceneCreate() apply.

◆ OnSceneCreate()

virtual void MultiStation::ISystemModule::OnSceneCreate ( Scene & scene)
virtualnoexcept

Prepares module resources for a newly created or loaded scene.

Parameters
[in,out]sceneLive scene with its initial data ready for use.

Use this to prepare per-scene settings or resources without making the scene active. The default implementation does nothing.

Note
SystemManager notifies initialized modules even when their system updates are disabled. Notifications are synchronous in registration order.
Warning
Run scene callbacks at a safe stage with no jobs accessing the affected scene. Do not mutate module registration, initialize/finalize modules, or trigger nested lifecycle dispatch from these callbacks.

◆ OnSceneDeactivate()

virtual void MultiStation::ISystemModule::OnSceneDeactivate ( Scene & scene)
virtualnoexcept

Stops using a scene as the active scene without destroying it.

Parameters
[in,out]scenePreviously active scene, still valid during the call.

Release active-scene bindings here. The scene may remain loaded and become active again, or be destroyed afterward. No replacement scene is guaranteed. The default implementation does nothing.

Precondition
The safe-stage and callback restrictions of OnSceneCreate() apply.

◆ OnSceneDestroy()

virtual void MultiStation::ISystemModule::OnSceneDestroy ( Scene & scene)
virtualnoexcept

Releases module resources and references before scene destruction.

Parameters
[in,out]sceneScene that is still alive for the duration of the call.

Do not retain references to the scene after destruction. This notification does not save the scene; settings needed by serialization must be synchronized before saving. The default implementation does nothing.

Precondition
If active, the scene has received OnSceneDeactivate() first. The safe-stage and callback restrictions of OnSceneCreate() apply.
