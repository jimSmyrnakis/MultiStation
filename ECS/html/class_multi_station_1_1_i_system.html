Detailed Description

Base interface for a module's system, driven by SystemManager.

After module Init(), the manager calls OnAttach(), then OnEnable(). Each frame it processes enable/disable changes before calling OnUpdate() on enabled systems, in module registration order. OnEnable() and OnDisable() may repeat as the requested enabled state changes.

When the module is removed or the manager shuts down, OnDisable() is called if the system was last processed as enabled, then OnDettach(), followed by module Fini(). Destruction alone does not invoke these callbacks.

Note
All lifecycle callbacks have empty default implementations.
Warning
Callbacks must not let exceptions escape, add or remove modules, or recursively update the manager.
